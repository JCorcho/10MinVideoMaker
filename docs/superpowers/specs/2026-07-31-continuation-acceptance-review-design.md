# Continuation Acceptance Review Screen

## Goal

Let the owner review each bounded LTX continuation case without using File Explorer or interpreting extracted-frame filenames.

## Scope

Extend the existing authenticated FastAPI supervisor GUI with a read-only acceptance-review route. It operates only on a completed run beneath `D:\LTX_Supervisor_Storage\acceptance\<run_id>` and its corresponding project-owned raw artifacts under `D:\LTX_Supervisor_Storage\jobs\<run_id>`.

The route does not start or control the supervisor, change job state, queue ComfyUI work, alter raw artifacts, or approve continuation rollout.

## Review data

`run.json` is the source of truth for case names and raw MKV paths. The server validates every path is inside the project-owned storage root and exists before exposing it.

The server creates an unwatermarked, browser-safe H.264/AAC MP4 review proxy for each valid raw window on demand. Proxies are stored only under `D:\LTX_Supervisor_Storage\acceptance\<run_id>\review\`. Existing matching proxies are reused. Raw FFV1/FLAC videos remain unchanged.

## Screen

The page contains:

- case selector: `single_frame`, `decoded_17_frame`, `latent_overlap`;
- left video: shared base window;
- right video: selected continuation window;
- a `Show seam` control that seeks both videos to the exact comparison boundary;
- labeled seam stills generated by the acceptance runner;
- plain-language visual checklist: identity/anatomy, hand/object contact, camera motion, freeze/jump, and visible seam;
- link/button back to the normal supervisor GUI.

Exact labels:

- `single_frame`: left frames 119/120; right frames 0/1; boundary is left 120 to right 0.
- `decoded_17_frame`: base guide frames 96–112; right guide frames 0–16; new-motion seam is right 16 to 17.
- `latent_overlap`: base guide frames 96–120; right guide frames 0–24; new-motion seam is right 24 to 25.

`common_base` is base reference only; it is never presented as a competing continuation method.

## Error handling

Missing or invalid run documents, paths, FFmpeg failures, and unavailable proxy media show a human-readable page error. The page does not fall back to arbitrary files or cross-job media.
